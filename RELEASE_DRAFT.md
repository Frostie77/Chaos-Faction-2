# Chaos Faction 2 Android v0.1.0

The first public Android release of **Chaos Faction 2**, powered by **Ruffle** and **FrostFrontend**.

**Features**

- Remappable gamepad controls and configurable movement settings.
- Touch joystick or D-pad, plus Attack 1, Attack 2, Melee and Drop buttons.
- Custom touch layouts: reposition individual buttons and the movement pad, then save your layout between launches.
- Original 4:3 display or stretch to screen.
- Native left/right/both speaker test.
- Game progress and settings saved locally.
- Optional release update checks through FrostFrontend.
- Custom CF2 launcher artwork.

**Getting started**

1. Download and install the APK attached to this release.
2. Download the [original Chaos Faction 2 SWF from Armor Games](https://cache.armorgames.com/files/games/chaos-faction-2-5645.swf).
3. Open the app and select `chaos-faction-2-5645.swf`.

Requires **Android 8.0 or newer**. The SWF is not bundled with the APK.

The signed release was tested on the **AYN Odin 2 Portal**. Other devices and multiplayer controller assignment have not yet been verified.
