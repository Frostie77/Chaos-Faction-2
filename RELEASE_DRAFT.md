# Chaos Faction 2 Android v0.1.0

The first public Android build of Chaos Faction 2, powered by Ruffle and FrostFrontend.

- Remappable gamepad controls and configurable movement settings.
- Touch joystick or D-pad, with Up to jump/double jump and Down to shield/stomp.
- Attack 1, Attack 2, held Melee modifier and Drop touch buttons.
- Built-in touch layout editor: move individual buttons and the movement pad, save positions between launches, cancel changes or reset the layout.
- Original 4:3 display or stretch to screen.
- Native left/right/both speaker test.
- Game progress and settings saved locally between launches.
- Optional verified release checks through FrostFrontend; available updates open their GitHub release page.
- Metallic CF2 launcher artwork with an orange blast and surrounding weapons.

Requires Android 8.0 or newer. Install the APK, open it and import your original `chaos-faction-2-5645.swf`. The game file is not included.

Tested in development on the AYN Odin 2 Portal. Performance and compatibility on other devices and multiplayer controller assignment have not been verified.

Original game by EON / Dissolute Productions, with art by mungo-raginbrain; originally published by Armor Games. Android adaptation by Frostie77. Built with Ruffle and FrostFrontend.
